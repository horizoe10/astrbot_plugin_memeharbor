<h1 align="center">表情港湾 MemeHarbor</h1>
<p align="center"><strong>收一次，找得快，每次都有新回应。</strong></p>
<p align="center">表情包收集 · 群聊斗图 · 多标签搜图 · 随机发图 · 可视化图库<br>面向 AstrBot 各群聊平台 · v1.3.0</p>
<p align="center"><a href="#三步开始">三步开始</a> · <a href="#网页图库">网页图库</a> · <a href="https://github.com/horizoe10/astrbot_plugin_memeharbor/issues">反馈问题</a></p>

群里看到好图就收下，想斗图时按标签找出来。**表情港湾 MemeHarbor** 把表情包收集、多标签搜图和随机发图连成一个流程：给图片打标签，翻看带编号的预览，再把合适的原图发回群里。随机斗图会优先避开本群最近发过的图，让收藏的好图随叫随到。

MemeHarbor 基于 AstrBot 的统一消息接口收发图片，适用于所有接入 AstrBot 的群聊。具体的图片、引用和发送能力取决于所用的平台适配器。

## 功能

- **随手收集**：图片和命令一起发、引用图片或合并转发的聊天记录、先发命令再补图都可以；同一张图自动合并标签。
- **组合搜图**：多个标签同时满足、排除标签、满足其一；每张图有固定编号。
- **预览再发送**：一张拼图看一页，每个人独立翻页；发送原文件，GIF 保持动图。
- **不总发同一张**：按群记住最近发过的图，并支持发图冷却和单次数量上限。
- **网页图库**：标签栏筛选、大图预览、标签自动补全、「待整理」逐张整理、跨页批量操作、拖入文件夹导入。
- **相似图片**：找出被压缩、转发后变得不同的同一张图，一键合并标签。
- **图库范围**：可以所有群共用一个图库，也可以让每个群使用自己的图库。
- **整理可撤销**：标签增删、全库重命名、回收站恢复；移除标签不会删除原图。
- **AI 按需开启**：图片描述、图中文字识别、标签建议和自然语言找图，默认关闭。

## 安装

需要 AstrBot **4.29.0-beta.1 或更新的 4.x**，Python **3.12+**。在 AstrBot 后台：插件 → 安装插件 → 从链接安装：

```text
https://github.com/horizoe10/astrbot_plugin_memeharbor
```

也可以在 [Releases](https://github.com/horizoe10/astrbot_plugin_memeharbor/releases) 下载 ZIP，选择「从文件安装」。安装后，在机器人使用的配置文件里启用 **表情港湾 MemeHarbor**。

## 三步开始

在群里按平台方式 @机器人（或加唤醒前缀），附上图片发送：

```text
/收集 猫 憋笑
/搜图 猫 憋笑
/发图 12
```

`12` 换成预览图里的编号。发送 `/斗图帮助` 查看全部命令。

| 想做什么 | 发送什么 |
|---|---|
| 收图 | `收集 猫 憋笑` 附图，或引用图片、聊天记录 |
| 批量收聊天记录里的图 | 引用合并转发的记录，发送 `导入记录 猫` |
| 先发命令再补图 | `收集 猫`，60 秒内同一人补发图片；`取消收集` 可取消 |
| 多个标签同时满足 | `搜图 猫 憋笑` |
| 排除标签 | `搜图 猫 -伤心` |
| 满足其一 | `搜图 猫 \| 狗` |
| 浏览与翻页 | `查看图片`，之后发 `下一页` `上一页` 或 `图片翻页 2` |
| 随机斗图 | 直接发已有标签，或 `随机图 猫 3` |
| 改标签 | `标签添加 12 可爱`、`标签移除 12 憋笑` |
| 全库改标签名 | `标签重命名 旧 新`（管理员） |
| 删除与恢复 | `删除图片 12`、`图片回收站`、`恢复图片 12` |
| 查看信息 | `图片详情 12`、`标签列表`、`图库统计` |
| AI 辅助 | `识图 12`、`AI搜图 一只假装生气的猫`（需开启） |

「下一页」「上一页」只在你刚搜过图的 10 分钟内由本插件响应，其他时候留给别的插件使用。回收站命令是「图片回收站」，也可以发「斗图 回收站」。所有命令都可以加「斗图」前缀，例如「斗图 搜图 猫」。

关闭配置「需要 @机器人 或唤醒前缀」后，可以直接发「收集 猫」这样的命令。带 / 的命令始终可用。

## 从聊天记录收图

1. 把含有图片的聊天记录合并转发到群里。
2. 引用这条记录，发送 `/导入记录 猫 憋笑`。
3. 记录里的图片会一起收进图库，并统一打上这些标签；已有的图会合并标签，不限制数量。

部分图片或嵌套记录失效时，插件会报告读取失败的数量，并继续处理其余内容。直接带图片内容的平台都能使用；OneBot 还会通过协议端接口展开记录和嵌套转发。平台只提供记录 ID、不提供内容时（例如 QQ 官方机器人的部分记录），插件会提示你展开后发送图片，或改用网页导入。

## 网页图库

入口：AstrBot 后台 → 插件 → 表情港湾 MemeHarbor → **Pages**。

- **左侧**：在全部图片、待整理、相似图片、统计和回收站之间切换；标签栏显示每个标签的数量，点击即可筛选。
- **中间**：搜索框会自动补全标签，可以按最新、最早、最常发送或待整理优先排序；勾选图片后可批量加减标签或移入回收站，也可以选中全部搜索结果。
- **右侧**：查看大图（GIF 会动），用标签块编辑标签；← → 切换图片，Ctrl + Enter 保存并跳到下一张。

**整理新图**：网页导入的图和没写标签的收集，都会放进「待整理」。打开「待整理」，逐张输入标签并按回车保存，插件会自动去掉「待整理」并跳到下一张。

**导入**：把图片、ZIP 或整个文件夹拖进页面即可导入，子文件夹也会读取；导入数量不限，并显示进度。支持 JPG、PNG、GIF、WebP、BMP。重复的图片自动合并，损坏的图片单独报错，不影响其他图片。普通 ZIP 最大 30 MB、展开后最大 150 MB；图片较多时，建议直接导入文件夹。

**相似图片**：首次打开时会分析已有图片，之后新收集的图片会自动分析。每组相似图片中，可以选一张保留，把其余图片的标签和发送次数合并进来，被合并的图片移入回收站。分到同一组但其实不是同一张时，点「不是同一张」，以后就不会再提示。

**备份**：「导出备份」会打包全部图片、标签、描述和回收站状态。导入备份时按图片内容合并，编号可能和原来不同。

## 图库范围

配置「图库范围」默认是 **所有群共用一个图库**。改为 **每个群使用自己的图库** 后：

- 每个群只能搜到和发送本群收集的图片，以及从网页导入的图片；
- 同一张图被多个群收集时，这些群都能看到；
- 切换设置不会移动或删除任何图片，网页图库始终显示全部图片。

## AI 默认关闭

打开「开启 AI 识图和 AI 搜图」后，在「AI 使用的模型」里选择一个已配置的模型。识图需要支持视觉的模型。只有主动使用识图或 AI 搜图时才会调用模型，可能产生费用；识图会把所选图片发给模型。建议的标签需要手动采纳。AI 搜图只查看最近 200 张图已有的标签、描述和图中文字。

## 数据与权限

数据保存在 `data/plugin_data/astrbot_plugin_memeharbor/`。管理员可以管理所有图片；收集者默认可以管理自己收集的图片。黑白名单可以直接在配置中选择会话和用户，也可以手动填写群号或用户 ID。重启后，翻页记录、等待中的收图和最近发图记录会清空，图片、标签和发送次数不受影响。
