<h1 align="center">表情港湾 MemeHarbor</h1>
<p align="center"><strong>收一次，找得快，每次都有新回应。</strong></p>
<p align="center">表情包收集 · 群聊斗图 · 多标签搜图 · 随机发图 · 可视化图库<br>面向 AstrBot 各群聊平台 · v1.1.0</p>
<p align="center"><a href="#旧版迁移">旧版迁移</a> · <a href="https://github.com/horizoe10/astrbot_plugin_memeharbor/issues">反馈问题</a></p>

群里看到好图就收下，想斗图时按标签找出来。**表情港湾 MemeHarbor** 把表情包收集、多标签搜图和随机发图连成一个流程：给图片打多个标签，翻看带编号的预览，再把合适的原图发回群里。随机斗图会优先避开本群近期发过的图片，让收藏的好图随叫随到。

MemeHarbor 面向所有通过 AstrBot 接入的群聊，基于 AstrBot 的统一消息接口收集和发送图片。平台接入由 AstrBot 适配器负责，具体的图片、引用和消息发送能力以所用适配器为准。

## 从图片回复脚本，到可管理的表情库

- **随手收集**：图片与命令同发、引用图片、先发命令再补图；相同文件合并标签。
- **组合搜图**：多词同时满足、排除标签、任选条件；固定编号定位图片。
- **预览再发送**：一张拼图看一页，每个人独立翻页；发送原文件时保留 GIF。
- **不总发同一张**：按群记录近期内容，同批去重、冷却和数量上限。
- **整理可撤销**：标签增删、全库合并、收集者权限和回收站；移除标签不删除原图。
- **网页管理**：批量标签、图片上传、普通图片 ZIP 和整个文件夹导入，以及整库备份导入导出。
- **AI 按需启用**：描述、OCR、标签建议和自然语言搜索，默认关闭。

## 安装

需要 AstrBot **4.29.0-beta.1 或更新的 4.x**、Python **3.12+**。插件管理 → 从链接安装：

```text
https://github.com/horizoe10/astrbot_plugin_memeharbor
```

也可通过仓库 **Code → Download ZIP** 下载，再本地安装。安装后在机器人对应的配置文件中启用 **表情港湾 MemeHarbor**。

旧版用户请先备份并停用 Image Replay。新标识为 `astrbot_plugin_memeharbor`，首次空目录安装会复制旧图库，原始数据保留。

## 旧版迁移

1. 备份 `data/plugin_data/astrbot_plugin_image_replay/` 整个目录和旧插件配置。
2. 停用旧插件，再安装 MemeHarbor，避免两套插件同时响应相同命令。
3. 在机器人对应的配置文件中启用 MemeHarbor；原来只启用了旧插件的配置不会自动加入新插件。
4. 首次启动且新数据目录为空时，会复制旧图库和索引；SQLite 使用备份接口复制，原数据保留。已有 v2 图库的编号、标签、描述和回收站状态会保留。
5. 旧配置中已知的设置，仅在新配置对应项仍为默认值时继承。迁移后请检查唤醒、权限和自定义指令设置，并试发一张图片。

非空的新图库不会自动覆盖。ZIP 导入适合合并图库；需要回滚时，请停用插件后恢复完整数据目录备份。

## 三步开始

在已接入 AstrBot 的群聊中，按当前平台的唤醒方式（如 @机器人）附图并发送：

```text
/收集 猫 憋笑
/搜图 猫 憋笑
/发图 12
```

`12` 请替换为预览里的真实编号。`/memeharbor` 或 `斗图帮助` 查看帮助，也支持 `/memeharbor 搜图 猫`。

收集和网页批量上传不限制图片数量；群聊中会处理平台实际提供的全部图片。旧配置中的 `max_collect_count` 不再生效。单张图片的大小限制仍由 `max_image_mb` 控制。

| 想做什么 | 发送什么 |
|---|---|
| 多标签同时满足 | `搜图 猫 憋笑` |
| 排除标签 | `搜图 猫 -伤心` |
| 条件任选 | `搜图 猫 \| 狗` |
| 浏览与翻页 | `查看图片`、`下一页`、`上一页`、`图片翻页 2` |
| 随机斗图 | 直接发已有标签，或 `随机图 猫 3` |
| 编辑标签 | `标签添加 12 可爱`、`标签移除 12 憋笑` |
| 全库统一标签 | `标签重命名 旧 新`、`标签合并 旧 新`（管理员） |
| 删除与撤销 | `删除图片 12`、`回收站`、`恢复图片 12` |
| 查看详情 | `图片详情 12`、`标签列表`、`图库统计` |
| 两步收图 | `收集 猫`，60秒内同一人同一会话补图；`取消收集` 可取消 |
| AI 辅助 | `识图 12`、`AI搜图 一只假装生气的猫`（需启用） |

`/收集` 兼容全局唤醒前缀为空的情况；`require_wake=false` 时也能裸发 `收集`。开启该配置时，裸命令和快捷标签仍需 @ 或唤醒。消息是否交给机器人，由平台接收规则和 AstrBot 配置共同决定。

## 跨平台兼容与差异

收集优先读取 AstrBot 标准图片和引用消息组件；原图与分页预览使用统一图片消息发送，不依赖某个平台的合并转发功能。搜图、标签管理、回收站和防重复选择使用同一套逻辑。

- **通用群聊适配器**：提供标准图片组件及图片发送能力即可使用基本收集和发图流程。
- **QQ 官方适配器**：补充识别其附件和引用附件格式。
- **OneBot 适配器**：引用中缺少原图时，额外尝试通过其消息与图片接口补取。
- **引用信息不完整的平台**：把图片与命令同发，或先发收集命令再补发图片。

平台专用接口只在对应适配器上调用。平台是否支持原格式动图、引用原图及特定消息类型，取决于适配器与平台本身的能力。

单次默认最多3张原图，同一用户默认2秒冷却。近期去重按机器人和群隔离，不因同群用户会话隔离而失效。只有一张图时无法避免重复；指定编号发图不参与随机选择，但仍受冷却限制。平台审核、被动回复次数和频率限制仍然适用。

## 网页图库与备份

入口：**插件详情 → Pages → 表情港湾 MemeHarbor · 图库管理**。登录面板后即可浏览、批量整理、下载原图和恢复回收站。新上传的图使用“待整理”标签。

点击 **导入图片 / ZIP** 可多选图片、普通图片压缩包或本插件导出的备份；点击 **导入整个文件夹** 可选择本机目录，自动包含子文件夹内的图片。支持 JPG、PNG、GIF、WebP、BMP，普通 ZIP 中的非图片文件会跳过，不会递归打开嵌套 ZIP。普通图片默认使用“待整理”标签，可在导入后批量整理。

图片、文件夹及备份 ZIP 均不设置导入数量上限。文件夹逐张上传，普通 ZIP 逐张读取；重复图片自动合并，普通 ZIP 中的损坏图片会单独报错并继续导入其余图片。页面显示新增、重复、跳过与失败数量。

ZIP 导入按内容合并，编号可能变化，不是原地回滚；插件备份保留标签、描述及回收站信息，已有图片的描述和回收站状态不会被覆盖。ZIP 上传最多 30 MB，展开图片最多 150 MB，备份索引最多 5 MB；单张图片仍受 `max_image_mb` 限制。大图库建议使用文件夹导入；不支持目录选择的浏览器可使用多选图片或 ZIP。回收站不会自动清空。

## AI 默认关闭

开启 `ai_enabled`，选择已有的 AstrBot 模型提供商 ID（不是 API Key）。识图需视觉模型。聊天可沿用会话模型，网页识图需明确填写提供商 ID。

只有显式请求才调用 AI；识图会把所选图片发给模型，可能产生费用。建议标签需要手动采纳。AI 搜图使用最近200张图已有的标签、描述和 OCR，最多返回24张候选；它不是全库向量搜索，不会自动分析全部原图。

## 数据与权限

数据保存在 `data/plugin_data/astrbot_plugin_memeharbor/`。`library_v2.sqlite3` 的 v2 是索引格式，与 MemeHarbor 的插件版本号无关。

各群共享图库。默认管理员和原收集者能管理对应图片；旧图没有收集者记录的由管理员管理。群/用户黑白名单填写对应 AstrBot 适配器提供的 ID，例如 QQ 官方使用 openid。重启清空翻页、待收图和近期去重记录，图片、标签与累计发送数保留。
