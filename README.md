群里看到好图就收下，想斗图时张口就来。适用于所有接入 AstrBot 的群聊，图片能力取决于各平台适配器。

<p align="center"><strong>📥 收图 → 🗂️ 整理 → 🔍 搜图 → 🎯 发图 → 🔁 换一张 / 👍 好图 → 📊 越用越懂你的群</strong></p>

## ✨ 亮点

| | 功能 | 一句话 |
|:-:|---|---|
| 📥 | 随手收集 | 附图、引用图片、合并转发的聊天记录都能收，重复的图自动合并标签 |
| 🔍 | 组合搜图 | 多标签、排除、任选其一，部分匹配，搜不到时推荐相近标签 |
| 🎲 | 张口就来 | 发「猫」或「来张猫」就回图，可按群免 @，「换一张」随时换 |
| 🖼️ | 以图回图 | 引用一张表情发「回一张」，回一张同类但不同的图 |
| ♻️ | 不炒冷饭 | 同一个群一段时间内不重复，少发被嫌弃的，多发被夸的 |
| 🖥️ | 网页后台 | 数字键整理、标签合并与别名、群聊洞察、相似图片一键合并 |
| ↩️ | 改错不怕 | 网页和群里的修改都能撤销，定期自动备份 |
| 🤖 | AI 可选 | 识图、图中文字识别和自然语言找图，默认关闭 |

## 🚀 30 秒上手

**安装**：AstrBot 后台 → 插件 → 安装插件 → 从链接安装，填入下面的地址；或在 [Releases](https://github.com/horizoe10/astrbot_plugin_memeharbor/releases) 下载 ZIP 后从文件安装。需要 AstrBot 4.29.0-beta.1 及以上的 4.x 版本。

```text
https://github.com/horizoe10/astrbot_plugin_memeharbor
```

**试用**：在群里 @机器人（或加唤醒前缀），依次发送：

| 步骤 | 发送 | 结果 |
|:-:|---|---|
| 1️⃣ | `收集 猫 憋笑` ＋ 图片 | 📥 图片存进图库，带上两个标签 |
| 2️⃣ | `搜图 猫` | 🧩 收到一张带 1～9 序号的预览图 |
| 3️⃣ | `3` | 🎯 发出第 3 张原图，GIF 保持动图 |

> 💡 带 `/` 的命令始终可用；发送 `斗图帮助` 查看全部命令。

## 💬 群聊命令

| | 想做什么 | 发送 |
|:-:|---|---|
| 📥 | 收图 | `收集 猫 憋笑` 附图，或引用图片、聊天记录；先发命令、60 秒内再补图也行 |
| 📚 | 收聊天记录里的图 | 引用合并转发的记录，发 `导入记录 猫` |
| 🔍 | 搜图 | `搜图 猫 憋笑` 同时满足 · `搜图 猫 -伤心` 排除 · <code>搜图 猫 &#124; 狗</code> 任选其一 |
| 📖 | 翻页、取图 | `下一页` `上一页` · 回复序号 `3` 或 `发 1 3` · `发图 12` 按编号 |
| 🎲 | 随机发图 | `随机图 猫 3` |
| 🏷️ | 改标签 | `标签添加 12 可爱` · `标签移除 12 憋笑` · `标签重命名 旧 新`（管理员） |
| 🗑️ | 删除、恢复 | `删除图片 12` · `图片回收站` · `恢复图片 12` |
| ↩️ | 撤销 | `撤销修改`：撤销自己最近一次修改，管理员可撤销任何人的 |
| ℹ️ | 查看 | `图片详情 12` · `标签列表` · `图库统计` |
| 🤖 | AI（需开启） | `识图 12` · `AI搜图 一只假装生气的猫` |

## 🎲 斗图玩法

| 群里说 | 机器人会 | 什么时候有效 |
|---|---|---|
| `猫` `来张猫` `来两张猫图` | 🎯 发猫的图，避开本群最近发过的 | @机器人，或开启「斗图免 @」的群 |
| `换一张` `再来` | 🔁 换一张同类的，这一轮不重复 | 机器人发图后 2 分钟内，谁说都行 |
| `好图` | 👍 记一笔，以后多发这张 | 机器人发图后 2 分钟内 |
| `3` `发 1 3` | 🧩 从预览图里取原图 | 自己搜图后 10 分钟内 |
| 引用表情 ＋ `回一张` | 🖼️ 回一张同类但不同的图 | @机器人，或开启「斗图免 @」的群 |
| `来张某某`（没有这个标签） | 💡 推荐相近的标签 | @机器人时 |

## 🧩 可选开关

都在插件配置里，按群生效；不确定时先在一个群里试。

| 开关 | 默认 | 打开后 |
|---|:-:|---|
| 🙌 斗图免 @ | ⚪ 关 | 选中的群里直接发标签就回图，每群有几秒冷却 |
| 😏 接梗模式 | ⚪ 关 | 群友提到标签或发表情时，按概率（默认 15%）接一张，每群冷却 5 分钟 |
| 🧲 自动收集 | ⚪ 关 | 同一张图 24 小时内被 2 个人发过，就静默收进「待整理」 |
| 📝 投稿审核 | ⚪ 关 | 非管理员收的图先进「待审核」，通过后才能搜到 |
| 🏠 每群独立图库 | ⚪ 关 | 各群只看到本群收的图，以及网页、备份和早期导入的图 |
| 🔎 部分匹配 | 🟢 开 | 「搜图 猫」也能找到「猫猫头」，完全一致的排在前面 |
| ♻️ 防重复 | 🟢 6 小时 | 同一个群在这段时间内尽量不重复发同一张 |
| 🗜️ 发图压缩 | 🟢 10 MB | 超过上限的图自动压缩后再发，GIF 保持动图 |
| 💾 自动备份 | 🟢 每 7 天 | 保留最近 3 份，存在插件数据目录的 `backups` 里 |
| 🤖 AI 识图 / 搜图 | ⚪ 关 | 需要选择模型，识图要支持视觉；只在主动使用时调用 |

> ⚠️ 自动收集会读取群里发的图片，请在群友知情时开启。

## 🖥️ 网页后台

入口：AstrBot 后台 → 插件 → 表情港湾 MemeHarbor → **Pages**。跟随面板的深浅色主题，支持手机。

| 页面 | 能做什么 |
|---|---|
| 🏠 首页 | 今天该做的事：待审核、待整理、相似图片、搜不到的词、标签健康；最近的修改和撤销 |
| 🗂️ 整理 | 逐张给新图打标签，或把长得像的新图整组打标签 |
| 🖼️ 图库 | 瀑布流浏览、搜索、批量加减标签、审核投稿、回收站 |
| 🏷️ 标签 | 封面和使用数据；重命名、合并、别名；找出重复的写法 |
| 📊 洞察 | 群友常搜什么、哪些词搜不到、最常发的图；预览某个群会收到什么 |
| 🧬 相似图片 | 逐组合并或一键全部合并，整次可撤销 |

<details>
<summary>⌨️ 快捷键</summary>

| 按键 | 作用 |
|---|---|
| `Ctrl` + `K` | 命令面板：`合并 猫猫 到 猫` `别名 喵 是 猫` `改名 A 为 B` `#12` |
| `1`～`9` · `Enter` | 整理时选推荐标签 · 保存并下一张 |
| `S` / `→` · `←` · `Z` · `Delete` | 跳过 · 上一张 · 撤销 · 移入回收站 |
| `Shift` ＋ 点击 | 图库里连续多选 |
| `/` | 跳到图库搜索框 |

</details>

<details>
<summary>📦 导入与备份</summary>

- 把图片、ZIP 或整个文件夹拖进网页即可导入，数量不限，重复的图自动合并。
- 支持 JPG、PNG、GIF、WebP、BMP；普通 ZIP 最大 30 MB，图多时建议直接导入文件夹。
- 「导出备份」打包全部图片、标签和描述；导入备份时按图片内容合并。

</details>

<details>
<summary>📚 从聊天记录收图</summary>

引用一条合并转发的聊天记录，发送 `导入记录 猫 憋笑`，记录里的图片会全部收进来，嵌套的转发也会展开。OneBot 协议端可以读取记录内容；平台只给出记录 ID 时（例如 QQ 官方机器人的部分记录），插件会提示你展开后再发，或改用网页导入。

</details>

## 🔒 数据与权限

| | 说明 |
|:-:|---|
| 📁 | 数据保存在 `data/plugin_data/astrbot_plugin_memeharbor/` |
| 👮 | 管理员可以管理所有图片；收集者默认可以管理自己收集的图 |
| 🚦 | 黑白名单可以直接选择群和用户，也可以手动填写 ID |
| 📈 | 搜索和发图记录只保存搜索词、图片编号、结果数量和所在群 |
